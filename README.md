# CV Application Maker

A React application that lets users build a CV by entering personal information, educational background, and practical experience. The information is displayed in a CV preview as the user fills out the sections.

## How to Use

Personal Information
1. Enter your full name, email, phone number, and address.
2. Select Submit to save the information and update the CV preview.
3. Select Edit to load your saved information back into the form.
4. While editing, changes are reflected in the preview.

Educational Background
1. Enter the school or university, degree/course, and year.
2. Select Submit to add the education entry to your CV.
3. Repeat these steps to add more education entries.
4. Select Edit to load a saved entry into the form.
5. If there are multiple entries, select Edit again to move to the next one.
6. After the last entry, selecting Edit again returns the form to its empty state so you can add a new entry.
7. While editing an entry, changes appear in the preview. If you clear every field, the entry is automatically removed.

Practical Experience
1. Enter your position/role, company, description, and year.
2. Select Submit to add the experience entry to your CV.
3. Repeat these steps to add more experience entries.
4. Select Edit to load a saved entry into the form.
5. If there are multiple entries, select Edit again to move through them.
6. After the last entry, selecting Edit again returns the form to its empty state so you can add a new entry.
7. While editing an entry, changes appear in the preview. If you clear every field, the entry is automatically removed.

Note: The current form behavior prevents submitting an education or practical experience form while an existing entry is being edited. Finish editing before adding another entry.
